# DSH Desktop 用户指南

## 系统与启动

DSH Desktop 1.1.1 仅支持 Windows 10/11。目标电脑需安装 Node.js 22 或更新版本，并可使用 DeepSeek Harness CLI。桌面程序直接使用浏览器相同的 `web` profile；优先复用 `127.0.0.1:3080`，若 3080 未运行或被 Windows 排除，则使用 3092 启动同一 profile。

启动时立即显示主窗口，DSH 服务加载状态集成在主窗口内容区；服务就绪后在同一窗口切换到首个页签，不再创建独立加载窗口。启动失败详情也显示在该内容区。

正式安装使用名称带 `Setup` 的完整安装包：安装向导可选择目录、可随时取消，完成后会创建桌面快捷方式、开始菜单程序组，并注册到 Windows「已安装的应用」，可从系统设置或开始菜单执行卸载。本项目不再提供便携版。

## 窗口与页签

- 窗口使用操作系统原生标题栏（含原生最小化/最大化/关闭按钮），无自绘标题栏和菜单栏。
- 点击 `+` 新建页签；再次启动程序也会在现有窗口中新建页签，不产生第二个任务栏或托盘图标。
- 只有一个页签时不显示页签栏，内容区直接扩展到窗口内容区顶部。
- 存在两个或更多页签时，可点击页签上的铅笔按钮，或双击/右键页签进行命名和重命名；标题原位变为带高亮边框/聚焦环的行内输入框，Enter 保存、Esc 取消、失焦保存。
- 在「设置 → 外观设置 → 页签位置」中可把页签放到顶部、左侧或右侧，选择后即时重排生效。
- 默认关闭按钮会隐藏到托盘（窗口从任务栏消失，可从托盘菜单「显示主窗口」恢复）；从托盘选择「退出」会结束桌面端创建的后端进程树。复用的外部服务不会被停止。
- 设置和关于均在主窗口页签内打开，重复打开会复用已有页签，不会生成独立窗口。
- 设置页语言使用下拉菜单选择；保存后即时更新托盘及后续内置页面。
- 可按 `Ctrl+,` 打开设置页签，按 `F1` 打开关于/帮助页签。
- 「关于」页签提供“检查 DSH 更新”和“更新 DSH”；执行更新前会再次确认，成功后按需自动重启后端。

## 主题和图标

原生标题栏、页签和控件跟随应用的系统/深色/浅色主题（`nativeTheme`），使用 DeepSeek 蓝强调色，不使用紫色。EXE、任务栏和托盘均使用统一的「抱书」图标。

## 插件隔离

桌面程序不复制、镜像或重新安装插件。浏览器在 `web` profile 安装或卸载插件后，重启相应 DSH Web 服务即可同时反映到浏览器和桌面端。若 `3080` 已有当前桌面浏览器会话能访问的服务，桌面直接复用；否则回退 `3092` 启动服务。显式配置其他端口时使用该端口。新版后端登录链接由桌面端自动交换 Cookie，HTTP 401 不会被判为就绪。桌面自身设置由主窗口内置页签承载。

旧 `dsh-desktop-settings` 插件、源码目录及 probe profile 均已删除，程序不会检测、安装或加载该插件。

## Preview 验证流程

运行 `powershell -ExecutionPolicy Bypass -File scripts/build-preview.ps1` 会先结束可执行路径位于本项目 `dist` 内的进程树，再彻底删除整个旧 `dist`，随后生成用于验证的解压版和 `preview-manifest.json`。此阶段不会生成 Setup。

使用 `scripts/verify-preview.ps1` 复核版本、文件数量、大小和 SHA-256。只有用户确认 Preview 正确后，才能运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-installer.ps1 -FromValidatedPreview
```

## 故障排查

- 端口被占用且桌面会话无法认证：默认 3080 会回退 3092；回退端口或显式配置的端口仍不可用时，按错误提示处理占用服务。
- 启动失败：按界面提示检查仓库路径、Node.js、启动工具、依赖与构建产物，详见 [快速开始](../QUICKSTART.md)。
- Web 插件未更新：完成插件安装/卸载后重启 DSH Web 服务，再重新打开桌面程序。
- 界面尺寸异常：在设置中切换一次页签位置，或删除用户配置中的窗口尺寸后重启。
